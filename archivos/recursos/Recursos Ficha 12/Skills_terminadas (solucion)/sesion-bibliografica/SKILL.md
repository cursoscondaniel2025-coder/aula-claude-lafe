# Sesión bibliográfica

## Qué hace
Prepara una presentación de la sesión bibliográfica a partir de varios artículos sobre el mismo tema.

## Pasos
1. Lee todos los artículos adjuntos.
2. Para cada uno, resume: pregunta, diseño, número de pacientes, resultado principal y limitación principal.
3. Compara los artículos en una tabla.
4. Saca las conclusiones útiles para nuestro servicio.
5. Propón tres preguntas para el debate.

## Formato del resultado
- Presentación de PowerPoint de 6 a 8 diapositivas: portada · pregunta clínica · una diapositiva por artículo · tabla comparativa · conclusiones para el servicio · preguntas para el debate.
- Notas del orador en cada diapositiva para una sesión de 20 minutos.
- Si está activada la skill formato-hospital-la-fe, aplica su formato.

## Reglas
- Usa solo los datos de los artículos. No inventes cifras ni referencias.
- No incluyas datos de pacientes.
